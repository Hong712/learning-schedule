安医大护理考研执行助手（PWA版）

这不是苹果原生 IPA 安装包。
它是一个“可安装网页 App（PWA）”，部署到 HTTPS 网站后，可在 iPhone Safari 中“添加到主屏幕”，像 App 一样使用。

最快使用方式：
1. 把整个 kaoyan_pwa 文件夹上传到任意静态托管：Vercel / Netlify / GitHub Pages / Cloudflare Pages。
2. 用 iPhone Safari 打开部署后的网址。
3. 点击“分享” -> “添加到主屏幕”。
4. 之后即可像普通 App 一样从桌面打开。

已内置功能：
- 今日任务
- 月度计划进度
- 专注计时
- 数据本地保存
- 导出 / 导入 JSON 备份

如需苹果原生版本，我可以继续基于同一套逻辑输出 SwiftUI 工程源码。
